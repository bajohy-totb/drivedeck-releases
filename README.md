# DriveDeck

### 지도는 계속 보고, 옆에서는 원하는 앱을.

**한국어** · [English](README.en.md)

DriveDeck은 Android 차량용 기기에서 설치된 앱 두 개를 함께 사용하는 런처입니다. 가로로 긴 화면은 좌우로, 세로 화면은 위아래로 배치하고 사이드바에서 앱을 크게 볼 수 있습니다.

실행 중에는 시작할 때의 화면 방향을 고정합니다. 분할 방향과 조작 바 위치는 설정에서 바꿀 수 있습니다.

[**1.1.0 APK 다운로드**](https://github.com/bajohy-totb/drivedeck-releases/releases/download/v1.1.0/DriveDeck-1.1.0.apk) · [배포 기록](https://github.com/bajohy-totb/drivedeck-releases/releases) · [전체 사용 설명서](docs/guide.ko.md)

**1.1.0 정식:** 세이지·오렌지 색상의 새 화면, 사이드바 앱 목록과 설정, 가로·세로 분할, 즐겨찾기 팝업, 이름을 붙여 저장하는 앱 조합을 제공합니다. 기존 앱 위에 설치하면 저장한 설정을 유지합니다. Android 13 이상과 자체 무선 디버깅·루트·Shizuku 중 하나의 연결이 필요합니다.

![DriveDeck 1.1.0 두 앱 화면](images/ko-workspace.png)

*실제 Android 13 에뮬레이터 화면입니다. Organic Maps와 Android 시계는 별도 앱이며 DriveDeck에 포함되지 않습니다. 차량·주행 시험 사진은 아닙니다. [검증 범위와 제한](docs/validation.md)*

## 주요 기능

아래 표와 화면은 정식 1.1.0 기준입니다. **[1.1.1-rc2 시험 버전](docs/preview.ko.md)**은 앱별 120~640dpi, 스크롤 앱 서랍, 앱·순서·비율을 직접 고르는 홈 조합 편집을 제공합니다. 홈 조합은 한 번 눌러 열고 길게 눌러 기본 홈을 실행합니다. 앱 업데이트에서 **시험 버전 받기**를 켜면 받을 수 있습니다.

| 기능 | 할 수 있는 일 |
|---|---|
| 화면을 넓게 | 상단 전체 바 없이 앱을 표시합니다. 앱 이름 바는 필요할 때 켭니다. |
| 가로·세로 배치 | 자동·좌우·위아래 분할, 순서 뒤집기, 왼쪽·오른쪽·아래 조작 바를 선택합니다. |
| 앱 크게 보기 | 실제 앱 이름이 표시된 확대 버튼과 분할 화면 버튼으로 전환합니다. |
| 구분선 드래그 | 가운데 경계를 움직여 비율을 미리 보고 손을 놓아 적용합니다. 30~70% 범위이며 탭하면 비율 메뉴가 열립니다. |
| 앱 목록 | 전체·즐겨찾기·최근·내비·음악/영상·기타 필터와 이름 검색, 화면에 맞춘 격자와 페이지 이동을 제공합니다. |
| 앱 옵션 | 길게 누르거나 ⋯를 눌러 즐겨찾기, 단독 열기, 구역 열기, 앱 정보, 삭제를 선택합니다. |
| 즐겨찾기 | 별 버튼으로 최대 3개의 바로가기와 전체 목록을 엽니다. 실행 대상은 자동 분류 또는 선택한 구역으로 설정합니다. |
| 앱 조합 저장 | 홈 기본 조합과 이름을 붙인 조합 최대 8개를 저장합니다. 홈 버튼을 길게 눌러 목록을 엽니다. |
| 설정 | 화면·조작·앱·연결·업데이트를 왼쪽 메뉴에서 고릅니다. 서랍·중앙 창·아래 시트 형태를 선택합니다. |
| 입력·복구 | 보조 앱의 물리 키보드 입력, 사이드바 포커스 방지, 연결 재시도와 구역 크기 복구를 지원합니다. |
| 한국어·영어 | 기기 언어를 따르거나 앱 언어를 직접 선택합니다. |
| 업데이트·백업 | 정식/시험 채널에서 APK를 받고 Android에서 설치를 확인합니다. 배치와 즐겨찾기, 저장한 조합을 백업합니다. |

![사이드바와 격자 앱 목록](images/ko-apps.png)

**즐겨찾기 해제는 앱을 삭제하지 않습니다.** 앱 삭제는 Android 확인창을 거칩니다. 시스템 앱은 앱 정보에서 관리합니다. 단독으로 열기는 분할 화면 밖에서 해당 앱을 실행합니다.

## 설정과 언어

![새 설정 화면](images/ko-settings.png)

**설정 → 조작 → 언어 / Language**에서 기기 설정 따르기·한국어·English를 선택합니다. 앱 선택과 배치를 유지하며 Android 앱별 언어 설정과 연동합니다. 다른 앱의 지도·곡명·알림 원문은 번역하지 않습니다.

## 설치와 업데이트

1. **Android 13 이상**에서 APK를 기존 DriveDeck 위에 설치합니다.
2. 처음 사용한다면 [자체 연결·루트·Shizuku 안내](docs/guide.ko.md#1-시작하기)에 따라 연결하고 서로 다른 앱 두 개를 선택합니다.
3. **설정 → 업데이트 → 업데이트**에서 새 버전을 확인하고 다운로드합니다.
4. 설치를 누르면 Android 설치 확인창이 열립니다. 앱 설치 허용이 필요하면 허용하고 돌아와 다시 누릅니다.

자동 확인은 앱 실행·복귀 시 정상 확인 후 6시간, 실패 후 5분 간격으로 가능합니다. 수동 확인은 바로 할 수 있습니다. 다운로드와 설치 확인은 직접 진행합니다. 정식 채널은 1.1.0, 시험 채널은 1.1.1-rc2를 제공합니다. 주차 후 설치하세요.
