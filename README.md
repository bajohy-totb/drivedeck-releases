# DriveDeck

Android 13 이상 차량용 런처 DriveDeck의 설치 파일과 업데이트 안내를 배포합니다.

현재 시험 버전은 정식 1.0.0이 아닙니다. 차량의 루트 권한·제조사 화면 처리에 따라 연결과 앱 입력 동작을 확인해야 합니다.

## 설치와 업데이트

처음에는 [1.0.0-rc7 APK](https://github.com/bajohy-totb/drivedeck-releases/releases/download/v1.0.0-rc7/DriveDeck-1.0.0-rc7.apk)를 받아 기존 앱 위에 설치합니다. 앱과 설정을 지울 필요는 없습니다.

업데이트 기능이 포함된 버전부터는 **설정 → 기기 → 업데이트**에서 새 버전 확인, 다운로드, 설치를 진행할 수 있습니다. 시험 버전을 받으려면 **시험 버전 받기**를 켭니다. Android 설치 허용과 설치 확인이 필요할 수 있습니다. 주차한 뒤 설치해 주세요.

업데이트 파일은 크기·SHA-256·앱 패키지·버전·기존 앱과 같은 서명을 확인한 뒤 설치 화면에 전달합니다. 앱 선택과 즐겨찾기는 유지됩니다.

`updates/stable.json`은 정식 버전, `updates/preview.json`은 시험 버전 안내입니다. 정식 버전이 아직 없다면 stable 안내도 제공되지 않습니다.

에뮬레이터에서 공개 APK 다운로드, 검증, 재실행 후 파일 복구, Android 업데이트 설치, 기존 설정 보존을 확인했습니다. 별도 기능 검사 중 화면 종료 시 약 6.8초 지연이 관찰됐고, 기존 차량의 음소거 멈춤·연결 끊김 문제는 해결 확인 전입니다. 자세한 내용은 [RC7 배포 기록](https://github.com/bajohy-totb/drivedeck-releases/releases/tag/v1.0.0-rc7)에 있습니다.
