# M4 Launcher

### 지도는 계속 보고, 옆에서는 원하는 앱을.

**한국어** · [English](README.en.md)

M4 Launcher는 Android 차량용 기기에서 설치된 앱 두 개를 함께 사용하는 런처입니다. 가로로 긴 화면은 좌우로, 세로 화면은 위아래로 배치하고 조작 바에서 한 앱을 크게 볼 수 있습니다.

M4 Launcher는 DriveDeck의 새 이름입니다. 1.2.1까지는 DriveDeck이었습니다. 같은 앱이므로 기존 DriveDeck 위에 그대로 설치되고 설정을 유지합니다. 내려받는 주소와 설치 파일 이름(`DriveDeck-1.3.0.apk`)은 예전 이름 그대로입니다.

실행 중에는 시작할 때의 화면 방향을 고정합니다. 분할 방향과 조작 바 위치는 설정에서 바꿀 수 있습니다.

[**1.3.0 APK 다운로드**](https://github.com/bajohy-totb/drivedeck-releases/releases/download/v1.3.0/DriveDeck-1.3.0.apk) · [배포 기록](https://github.com/bajohy-totb/drivedeck-releases/releases) · [전체 사용 설명서](docs/guide.ko.md)

**1.3.0 정식:** 이름과 아이콘이 바뀌었습니다. 홈 화면을 새로 만들었습니다. 앱과 위젯을 원하는 칸에 놓고, 여러 페이지를 좌우로 넘기며, 아래의 하단 바에 자주 쓰는 앱을 둡니다. 앱을 다른 앱 위에 놓으면 폴더가 되고, 위젯은 네 방향 손잡이로 크기를 바꿉니다. 홈 화면 아래쪽에서 위로 쓸어 올리면 모든 앱 목록이 올라오고, ‘모든 앱’ 버튼을 원하는 곳에 놓을 수도 있습니다. 기본 홈 앱으로 쓰면 앱을 길게 눌렀을 때 그 앱의 바로가기가 나옵니다. 배경은 그려 둔 다섯 가지와 ‘내 사진’ 중에서 고릅니다. 설정은 한 틀 안에서 움직입니다. 왼쪽 분류는 항상 남고, 줄을 눌러 여는 화면은 페이지 자리에 열립니다. ‘홈 화면’ 분류가 생겼고 업데이트도 설정의 한 페이지가 됐습니다. 설정 → 일반에는 ‘아이콘 팩’이 생겼습니다. 조작 바의 분할 버튼과 양쪽 앱 버튼을 길게 누르면 그 자리에 열 앱을 바꿉니다. 화면이 낮아도 조작 바의 마지막 버튼이 잘리지 않고 온도가 다시 나옵니다. 쓰고 있는 구역은 얇은 테두리와 위쪽의 짧은 주황 표시로 알려 줍니다. 시스템 글꼴을 크게 했을 때 잘리던 글자는 자리에 맞춰지게 고쳤습니다. 설정 백업에 홈 화면의 배치가 함께 들어갑니다. 위젯과 배경 사진은 들어가지 않습니다.

**알려진 한계:** 물리 키보드를 연결하고 화면 키보드를 숨겨 둔 채 Android 기본(AOSP) 키보드를 쓰면, 입력란을 누른 뒤 그 구역이 터치를 받지 않는 때가 있습니다. 보호 영상 호환 모드의 실제 넷플릭스 재생은 아직 확인하지 못했습니다. 기존 앱 위에 설치하면 설정을 유지합니다. Android 13 이상과 자체 무선 디버깅·루트·Shizuku 중 하나의 연결이 필요합니다. 실제 엠스틱4와 갤럭시 Z 폴드8로는 아직 확인하지 못했습니다.

![지도 앱과 다른 앱을 나란히 띄운 M4 Launcher 화면](images/ko-workspace.png)

*실제 Android 13 에뮬레이터 화면입니다. 지도 앱과 옆의 앱은 따로 설치한 앱이며 M4 Launcher에 포함되지 않습니다. 차량·주행 시험 사진은 아닙니다. [검증 범위와 제한](docs/validation.md)*

## 주요 기능

아래 기능은 정식 1.3.0 기준입니다. [앱 크기·앱 목록·조합 사용법](docs/preview.ko.md)도 확인하세요.

| 기능 | 할 수 있는 일 |
|---|---|
| 홈 화면과 위젯 | 홈 버튼으로 보조 구역에 홈 화면을 엽니다. 앱·폴더·위젯을 원하는 칸에 놓고 여러 페이지와 하단 바를 씁니다. 빈 곳을 길게 눌러 위젯이나 앱을 올리고, 올린 것을 길게 눌러 옮기거나 뺍니다. 아래쪽에서 위로 쓸어 올려 연 ‘모든 앱’에서 고른 앱은 그 구역에 열립니다. |
| 배경과 아이콘 팩 | 홈 화면 배경을 기본·숲·노을·슬레이트·종이·내 사진 중에서 고릅니다. 설정 → 일반 → 아이콘 팩에서 기기에 설치된 아이콘 팩을 고릅니다. |
| 어느 앱에서나 키보드 | 입력란을 누른 앱에 키보드가 열립니다. 마지막으로 누른 구역이 입력을 받고, 다른 구역을 끌거나 확대해도 입력 대상은 바뀌지 않습니다. |
| 화면을 넓게 | 상단 전체 바 없이 앱을 표시합니다. 앱 이름 바는 필요할 때 켭니다. |
| 가로·세로 배치 | 자동·좌우·상하 분할, 앱 위치 바꾸기, 왼쪽·오른쪽·아래 조작 바를 선택합니다. |
| 앱 크게 보기 | 조작 바의 앱 이름 버튼으로 한 앱을 크게, 분할 버튼으로 두 앱을 함께 봅니다. 이 버튼들을 길게 누르면 그 자리에 열 앱을 바꿉니다. |
| 구분선과 화면 비율 | 구분선을 끌어 5% 단위로 비율을 미리 보고 손을 놓아 적용합니다. 30~70% 범위입니다. 누르면 화면 비율 패널이 열리고 ‘위치 바꾸기’로 두 앱의 자리를 바꿉니다. |
| 앱 목록 | 분류·검색과 화면에 맞는 격자, 위아래 스크롤로 앱을 찾습니다. |
| 앱 옵션 | 앱을 길게 눌러 즐겨찾기, 구역에서 열기, 단독으로 열기, 앱 크기 (DPI), 보호 영상 호환 모드, 앱 정보, 앱 삭제를 선택합니다. |
| 즐겨찾기 | 별 버튼으로 최대 3개의 바로가기와 전체 보기를 엽니다. 실행 대상은 자동 분류 또는 선택한 구역으로 설정합니다. |
| 저장한 조합 | 설정 → 앱과 조합 → 앱 조합에서 최대 8개를 편집합니다. 조합 하나를 기본 홈으로 지정할 수 있습니다. |
| 설정 | 화면·조작 바·앱과 조합·홈 화면·연결·일반·업데이트를 왼쪽에서 고릅니다. 줄을 눌러 여는 화면도 같은 틀 안에 열립니다. 메뉴 위치는 오른쪽·가운데·아래 중에서 선택합니다. 홈 버튼을 길게 눌러도 열립니다. |
| 입력·복구 | 물리 키보드 입력, 조작 바의 키보드 포커스 방지, 연결 재시도, 구역 크기 복구, 커진 구역의 지도 다시 그리기를 지원합니다. |
| 한국어·영어 | 기기 언어를 따르거나 앱 언어를 직접 선택합니다. |
| 업데이트·백업 | 정식/시험 채널에서 APK를 받고 Android에서 설치를 확인합니다. 배치와 즐겨찾기, 저장한 조합, 홈 화면의 배치를 백업합니다. |

![분류와 검색이 있는 앱 목록](images/ko-apps.png)

**즐겨찾기 해제와 홈에서 빼기는 앱을 삭제하지 않습니다.** 앱 삭제는 Android 확인 창을 거칩니다. 기본 앱은 앱 정보에서 관리합니다. 단독으로 열기는 분할 화면 밖에서 해당 앱을 실행합니다.

## 홈 화면

![지도 옆 구역에 앱 아이콘과 위젯을 올린 홈 화면](images/ko-home.png)

*실제 Android 13 에뮬레이터 화면입니다. 지도와 위젯은 따로 설치한 앱이 제공하며 M4 Launcher에 포함되지 않습니다. 차량·주행 시험 사진은 아닙니다.*

홈 화면의 빈 곳을 길게 누르면 **위젯 추가**, **앱 추가**, **‘모든 앱’ 버튼 놓기**, **홈 화면 설정**이 나옵니다. 올린 것을 길게 눌러 끌면 원하는 칸으로 옮기고, 옆 가장자리로 끌면 다른 페이지로 넘어가며, 위쪽 막대에 놓으면 홈에서 뺍니다. 앱을 다른 앱 위에 놓으면 폴더가 됩니다. 길게 누른 뒤 그대로 떼면 옵션이 열리며, 위젯은 **크기 조절**을 고른 뒤 네 방향 손잡이를 끌어 칸 단위로 크기를 바꿉니다. 아래의 하단 바에는 자주 쓰는 앱을 두고, 그 끝의 버튼이나 위로 쓸어 올리기로 모든 앱 목록을 엽니다. 앱을 연 뒤 홈을 다시 누르면 홈 화면으로 돌아옵니다. 자세한 내용은 [사용 설명서의 홈 화면](docs/guide.ko.md#3-홈-화면)에 있습니다.

## 설정과 언어

![일곱 분류로 나뉜 설정 화면](images/ko-settings.png)

**설정 → 일반 → 언어 / Language**에서 기기 설정 따르기·한국어·English를 선택합니다. 앱 선택과 배치를 유지하며 Android 앱별 언어 설정과 연동합니다. 다른 앱의 지도·곡명·알림 원문은 번역하지 않습니다.

## 설치와 업데이트

1. **Android 13 이상**에서 APK를 기존 앱 위에 설치합니다.
2. 처음 사용한다면 [자체 연결·루트·Shizuku 안내](docs/guide.ko.md#1-시작하기)에 따라 연결하고 서로 다른 앱 두 개를 선택합니다.
3. **설정 → 업데이트**에서 새 버전을 확인하고 다운로드합니다.
4. 업데이트 설치를 누르면 Android 설치 확인창이 열립니다. 앱 설치 허용이 필요하면 허용하고 돌아와 다시 누릅니다.

자동 확인은 앱 실행·복귀 시 정상 확인 후 6시간, 실패 후 5분 간격으로 가능합니다. 수동 확인은 바로 할 수 있습니다. 다운로드와 설치 확인은 직접 진행합니다. 정식 채널은 1.3.0을, 시험 채널은 1.4.0-rc4을 제공합니다. 주차 후 설치하세요.
